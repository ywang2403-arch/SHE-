# SHE（她）
> Unity｜3D Horror Game

---

## 📖 项目简介 （Project Overview）
本项目是一款使用 Unity 3D 开发的第三人称心理恐怖游戏 Prototype，同时也是我硕士毕业论文（Practice-based Research）的实践作品。
游戏以一位迷失在森林中的女性为主角。玩家需要探索环境、收集散落的记忆碎片，并逐渐揭开主人公长期受到性别规训所形成的心理创伤。随着探索不断深入，游戏中的环境、声音以及系统规则也会不断发生变化，引导玩家重新思考”规则”与”自由”之间的关系。
与传统恐怖游戏依靠 Jump Scare 不同，本项目更希望利用游戏机制、环境叙事以及玩家行为本身制造心理压力，并通过程序修辞的方式，使玩家亲身体验被游戏系统（社会）规训、被限制以及最终选择反抗的过程。

## 💡 设计思考（Design Thinking）

本项目最大的设计目标并非”吓到玩家”，而是希望让玩家体验一种持续存在的心理压迫感。
因此，游戏没有采用大量 Jump Scare，而是通过以下方式逐渐建立恐怖氛围：
* 不断重复出现的规训性语言；
* 来自环境中的声音暗示；
* 玩家不断被系统要求”遵守规则”；
* 目标提示与游戏机制共同塑造压迫体验。
随着剧情推进，玩家逐渐意识到，这些声音并非来自怪物，而是来源于主人公成长过程中长期接受的社会期待与性别规训。
游戏希望借由互动体验，引导玩家思考：真正令人恐惧的究竟是怪物，还是那些不断塑造个体行为的社会规范。

## 🔄 设计迭代（Design Iteration）
环境叙事优化：项目初期主要依靠文字说明推进剧情，但在试玩过程中发现玩家容易忽略文本内容。因此后续将大量信息转移至环境设计、语音以及纸条收集系统，使玩家能够主动探索故事，而不是被动阅读剧情。

收集系统设计：为了避免传统收集玩法缺乏意义，每一张纸条都对应主人公人生中的一段经历，并搭配独立语音内容，使收集行为同时承担叙事推进与角色塑造两种功能。

目标（Objective）系统调整：
传统目标系统通常鼓励玩家完成任务，而本项目尝试利用目标系统作为”规训”的一部分，例如要求玩家遵守特定规则，从而使任务目标本身成为程序修辞的一部分，而不仅仅是导航工具。

音效设计：
相比突然出现的惊吓，本项目更加重视持续性的心理压力。通过环境噪音、远处歌声、重复出现的规训语音以及角色内心独白，共同塑造一种压抑且不安的游戏氛围。
